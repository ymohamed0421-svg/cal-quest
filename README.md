# Cal Quest

A game-style calorie, macro, water and steps tracker that runs as a web app on iPhone.

- Answer 7 questions (body, activity, goal) and get daily calorie, protein, carb, fat, water and step targets (Mifflin-St Jeor + activity multiplier).
- Log food from a built-in list of basics, USDA FoodData Central, or Open Food Facts. See macros plus fiber, sugar, sodium, potassium, calcium, iron and vitamin C.
- Count water in bottles, with 4 daily check-ins.
- Daily Quest with XP, levels, titles and streaks.

Everything is stored on the phone. No account, no server.

## Install on iPhone
Open the link in Safari, tap Share, then Add to Home Screen.

## Run locally
Any static file server works, e.g. `python3 -m http.server`.
